# XSYN Website

The official XSYN website.

XSYN is organized around the problems it helps industrial companies
understand, solve, and improve across product, operations, and technology.

## Core Domains

- Solutions
- Industries
- How We Work
- Experts
- Work
- Insights
- About
- Start a Problem

## Architecture

The project follows a modular, content-driven architecture:

- `content/` — business and editorial content
- `src/app/` — routes and application entry points
- `src/features/` — product capabilities
- `src/components/` — reusable UI and page composition
- `src/schemas/` — structured content and input contracts
- `src/lib/` — shared application logic
- `src/config/` — site configuration
- `src/types/` — shared TypeScript types
- `docs/` — architectural and product documentation
- `tests/` — automated tests
- `public/` — public assets
